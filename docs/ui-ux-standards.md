# Impactory UI/UX Standards

## 1. Product Feel
- Modern SaaS Blueprint.
- Premium but practical.
- System-first.
- Operator-led.
- Trust-focused.
- Not charity-template.
- Not generic AI-tool SaaS.

## 2. Navigation Behavior
- Route navigation scrolls to top.
- Hash anchor navigation may scroll to section.
- Sidebar links must preserve route consistency.
- No broken links.
- Coming soon cards must not link to missing routes.

## 3. Page Structure Standard
Every dashboard page should generally use:
- Page title.
- Short subtitle.
- Optional intro/trust card.
- Primary content.
- Workflow connection section if relevant.
- CTA back to Dashboard or next system step.
- No fake data.
- No unsupported claims.

## 4. Dashboard Page Spacing
- Use consistent max width/container.
- Use consistent vertical section spacing.
- Cards use global semantic tokens.
- Avoid page-only hardcoded colors.

## 5. Trust/AI UX Rules
- AI output is draft.
- Human Review Required for proposal, campaign, impact claims.
- No Fabrication.
- Sensitive data needs review.
- Do not imply AI submitted anything externally.

## 6. Empty State Standard
Empty states should answer:
- What is missing?
- Why it matters?
- What should user do next?
- If feature is not ready, say “segera hadir” and avoid broken links.

## 7. CTA Standard
- Primary CTA = next best action.
- Secondary CTA = related module.
- Avoid too many CTA buttons in one section.
- Disabled CTA must be visually clear.

## 8. Route/Page Checklist
Before marking a page done:
- Route starts at top on navigation.
- Title/subtitle clear.
- Mobile layout acceptable.
- No broken links.
- No fake data.
- No unsupported claims.
- Build/test pass.
